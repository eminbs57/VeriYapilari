SORU 1: AG YONETICISI VE BIPARTITE (IKI PARCALI) GRAF ANALIZI
================================================================================
Senaryo:
Bir ag yoneticisi, sunucular ve istemciler arasindaki baglantilari iki farkli kume 
(Istemciler U ve Sunucular V) arasinda organize etmek istemektedir. Kendi kumesi 
icindeki cihazlarin birbirine dogrudan baglanmasi guvenlik politikalari geregi yasaktir.

Girdi:
E = {(1, 2), (1, 4), (2, 3), (3, 4), (3, 6), (4, 5), (5, 6)}
Dugumler: {1, 2, 3, 4, 5, 6} (|V| = 6, |E| = 7)

CEVAPLAR:
--------------------------------------------------------------------------------
Gorev 1 - Komsuluk Matrisi (6 x 6):
     1  2  3  4  5  6 
   +------------------
 1 | 0  1  0  1  0  0 
 2 | 1  0  1  0  0  0 
 3 | 0  1  0  1  0  1 
 4 | 1  0  1  0  1  0 
 5 | 0  0  0  1  0  1 
 6 | 0  0  1  0  1  0 

Gorev 2 - Dugum Dereceleri ve Grafin Genel Derecesi:
• Dugum 1 Derecesi: 2 (Komsular: 2, 4)
• Dugum 2 Derecesi: 2 (Komsular: 1, 3)
• Dugum 3 Derecesi: 3 (Komsular: 2, 4, 6)
• Dugum 4 Derecesi: 3 (Komsular: 1, 3, 5)
• Dugum 5 Derecesi: 2 (Komsular: 4, 6)
• Dugum 6 Derecesi: 2 (Komsular: 3, 5)
• Grafin Toplam Derecesi: 14 (2 * |E| = 2 * 7 = 14)
• Grafin Maksimum Derecesi (Delta(G)): 3 (Dugum 3 ve 4)
• Grafin Ortalama Derecesi: 14 / 6 = 2.33

Gorev 3 - Bipartite Kontrolu (Baslangic: 1):
Baslangic dugumu 1'e Renk 0 (Mavi) ve Uzaklik 0 verilir:
• Dugum 1: Uzaklik 0 (Cift) -> Renk: 0 (Mavi)   -> Kume U
• Dugum 2: Uzaklik 1 (Tek)  -> Renk: 1 (Kirmizi) -> Kume V
• Dugum 3: Uzaklik 2 (Cift) -> Renk: 0 (Mavi)   -> Kume U
• Dugum 4: Uzaklik 1 (Tek)  -> Renk: 1 (Kirmizi) -> Kume V
• Dugum 5: Uzaklik 2 (Cift) -> Renk: 0 (Mavi)   -> Kume U
• Dugum 6: Uzaklik 3 (Tek)  -> Renk: 1 (Kirmizi) -> Kume V

SONUC: Graf IKI PARCALIDIR (Bipartite).
Kume U (Mavi / Cift Parite): { 1, 3, 5 }
Kume V (Kirmizi / Tek Parite): { 2, 4, 6 }
Guvenlik Politikasi: Kume icinde baglanti yoktur, ag politikaya uygundur.

Gorev 4 - Dinamik Test: (2, 4) Baglantisi Eklenirse:
• Cikti Degisimi: Program "Graf IKI PARCALI DEGILDIR (Not Bipartite)" ciktisi verir.
• Nedeni:
  1) 2 ve 4 numarali dugumlerin her ikisi de Kume V (Kirmizi / Tek parite) elemanidir.
  2) Aralarina (2, 4) kenari eklendiginde ayni renkte iki komsu olusur.
  3) Grafta 1 - 2 - 4 - 1 seklinde 3 kenarli tek uzunluklu bir dongu (odd cycle) olusur.
  4) Teorem: Bir graf ancak ve ancak hic tek uzunluklu dongu icermiyorsa iki parcalidir.
  5) Guvenlik acisindan: Kendi kumesi icindeki iki istemci birbirine dogrudan baglanarak
     guvenlik politikasi ihlal edilmistir.

Kaynak Kodu: cevaplar/soru1.c

SORU 2: EN AZ MALIYETLI YOL VE MERKEZI DUGUM ANALIZI (DIJKSTRA)
================================================================================
Senaryo:
6 dagitim merkezi (A, B, C, D, E, F) arasindaki en kisa teslimat rotalari ve 
en merkezi dagitim deposu belirlenecektir.

Kenarlar ve Maliyetler:
A-B: 7, A-C: 5, A-F: 1, B-C: 1, B-D: 1, B-E: 3, C-D: 2, C-E: 1, D-F: 7, E-F: 2

CEVAPLAR:
--------------------------------------------------------------------------------
Gorev 1 - Kok Dugum 'A' Icin Adim Adim Dijkstra Tablosu:
Adim 1 (Secilen: A): A=[0,-], B=[7,A], C=[5,A], D=[INF,-], E=[INF,-], F=[1,A]
Adim 2 (Secilen: F): F=[1,A], E=[3,F], D=[8,F]
Adim 3 (Secilen: E): E=[3,F], C=[4,E], B=[6,E]
Adim 4 (Secilen: C): C=[4,E], B=[5,C], D=[6,C]
Adim 5 (Secilen: B): B=[5,C]
Adim 6 (Secilen: D): D=[6,C]

Gorev 2 - Rota Ciktilari (Tersten Okuma Yontemiyle):
• Hedef B: A -> F -> E -> C -> B | Toplam Maliyet: 5
• Hedef D: A -> F -> E -> C -> D | Toplam Maliyet: 6

Gorev 3 - Merkezi Dugum Tespiti (Closeness Centrality):
Her dugum icin tum agdaki dugumlere en kisa mesafeler toplami:
• A Dugumu: A:0  B:5  C:4  D:6  E:3  F:1 -> Toplam Maliyet = 19
• B Dugumu: A:5  B:0  C:1  D:1  E:2  F:4 -> Toplam Maliyet = 13
• C Dugumu: A:4  B:1  C:0  D:2  E:1  F:3 -> Toplam Maliyet = 11
• D Dugumu: A:6  B:1  C:2  D:0  E:3  F:5 -> Toplam Maliyet = 17
• E Dugumu: A:3  B:2  C:1  D:3  E:0  F:2 -> Toplam Maliyet = 11
• F Dugumu: A:1  B:4  C:3  D:5  E:2  F:0 -> Toplam Maliyet = 15

SONUC VE KARAR:
En dusuk toplam maliyete sahip dugumler: C ve E (Toplam Maliyet: 11).
Eksantriklik (en uzak dugume mesafe):
• E dugumu icin maksimum mesafe = 3 birim (A ve D)
• C dugumu icin maksimum mesafe = 4 birim (A)
Bu nedenle E dugumu, tum lojistik agina en dengeli erisimi saglayan en merkezi depodur.

Kaynak Kodu: cevaplar/soru2.c

SORU 3: CAKISMASIZ SINAV TAKVIMI OLUSTURMA (WELCH-POWELL ALGORITMASI)
================================================================================
Senaryo:
6 farkli ders (d0, d1, d2, d3, d4, d5) icin cakismasiz final sinav programi.
Ogrenci Kayitlari:
• Ogrenci-1: d0, d1, d4
• Ogrenci-2: d0, d2, d4
• Ogrenci-3: d2, d3, d5
• Ogrenci-4: d3, d4, d5

CEVAPLAR:
--------------------------------------------------------------------------------
Gorev 1 - Otomatik Cakisma Grafi Modeli (Komsuluk Matrisi):
      d0  d1  d2  d3  d4  d5 
    +-------------------------
 d0 |  0   1   1   0   1   0 
 d1 |  1   0   0   0   1   0 
 d2 |  1   0   0   1   1   1 
 d3 |  0   0   1   0   1   1 
 d4 |  1   1   1   1   0   1 
 d5 |  0   0   1   1   1   0 

Gorev 2 - Welch-Powell Dugum Dereceleri Siralamasi:
1. d4 (Derece: 5)
2. d2 (Derece: 4)
3. d3 (Derece: 3)
4. d0 (Derece: 3)
5. d5 (Derece: 3)
6. d1 (Derece: 2)

Gorev 3 - Raporlama (Orijinal Durum):
• Gerekli Minimum Sinav Oturumu Sayisi (Kromatik Sayi): 4
  (Nedeni: {d2, d3, d4, d5} dersleri 4'lu tam klik (K4) olusturmaktadir).
• Oturum 1: { d4 }
• Oturum 2: { d2, d1 }
• Oturum 3: { d3, d0 }
• Oturum 4: { d5 }

Gorev 4 - Dinamik Guncelleme Testi (Ogrenci-4 d4 dersini birakirsa):
• Degisim: (d3, d4) ve (d4, d5) cakisma kenarlari silinir.
• Guncel Dereceler: d2(4), d0(3), d4(3), d3(2), d1(2), d5(2)
• Guncel Oturumlar:
  - Oturum 1: { d2, d1 }
  - Oturum 2: { d0, d3 }
  - Oturum 3: { d4, d5 }
• Guncel Kromatik Sayi: 3'e DUSTU (4 -> 3).
• Kazanım: K4 klik yapisi bozuldugu icin 1 sinav oturumu tasarrufu saglandi.

Kaynak Kodu: cevaplar/soru3.c
